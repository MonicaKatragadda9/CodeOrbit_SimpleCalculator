# CodeOrbit Tech - Simple Calculator

## Project Description
The Simple Calculator is a beginner-friendly Python program developed as part of the CodeOrbit Tech Python Programming Internship. It performs basic arithmetic operations based on user input.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero
- Handles invalid numeric input
- Displays results clearly

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run the Project
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

```bash
python calculator.py
```

## Sample Output

```text
Enter the first number: 10
Enter the second number: 5

Choose an operation:
1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
Enter your choice (1-4): 1
Result: 15.0
```

## Error Handling
The program handles invalid numeric input using `try/except` and prevents division by zero.

This project helped me understand Python variables, user input, arithmetic operators, conditional statements, and exception handling.
